# 兰心慧诊：基于多模态知识的女性肿瘤辅助诊断系统

## 🌸 项目简介

兰心慧诊是一个专注于女性肿瘤（宫颈癌、卵巢癌、子宫内膜癌、乳腺癌）的智能辅助诊断系统。系统集成了多模态数据分析、智能诊断、预后预测、病历生成、科研教学等功能，旨在为医生提供全方位的临床决策支持。

## ✨ 核心功能

### 🏥 智慧服务板块
- **疾病问诊**: 智能导诊、结构化症状采集、危险因素评估
- **病历生成**: 智能信息提取、专科病历格式生成
- **预后预测**: 生存预测、复发风险评估、动态预测更新
- **智能问答**: 专业问题解答、患者教育、治疗决策支持

### 🔬 智能诊断核心
- **多模态数据整合**: 文本、影像、病理数据融合分析
- **鉴别诊断系统**: 基于症状和检查结果的智能诊断
- **分期评估系统**: TNM分期和临床分期自动评估

### 📚 科研教学支持
- **临床研究支持**: 数据分析、统计方法推荐、样本量计算
- **教学案例库**: 典型病例管理、案例分析工具
- **继续教育平台**: 在线学习资源、学分认证

### 📖 循证决策支持
- 整合最新临床指南（NCCN、CSCO等）
- 提供个体化治疗的循证依据
- 最新研究证据汇总

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install flask requests python-dotenv
```

### 2. 启动系统
```bash
python run.py
```

### 3. 访问系统
打开浏览器访问: http://localhost:5000/lanxin

### 4. 功能演示
```bash
# 查看功能演示
python demo_showcase.py

# 测试API接口
python test_lanxin_api.py
```

## 🔌 API接口示例

### 症状采集
```bash
GET /api/diagnosis/symptom-collection/宫颈癌
```

### 风险评估
```bash
POST /api/diagnosis/risk-assessment
Content-Type: application/json

{
  "age": 45,
  "symptoms": ["异常阴道出血", "接触性出血"],
  "family_history": false
}
```

### 生存预测
```bash
POST /api/prognosis/survival-prediction
Content-Type: application/json

{
  "tumor_type": "宫颈癌",
  "stage": "IB",
  "age": 45
}
```

### 病历生成
```bash
POST /api/medical-record/generate
Content-Type: application/json

{
  "patient_info": {
    "name": "张女士",
    "age": 45
  },
  "diagnosis_info": {
    "preliminary_diagnosis": "宫颈癌疑似"
  },
  "tumor_type": "宫颈癌"
}
```
