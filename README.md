# 兰心慧诊 - 女性肿瘤辅助诊断系统

基于多模态知识的女性肿瘤辅助诊断系统，支持宫颈癌、卵巢癌、子宫内膜癌、乳腺癌的智能诊断和预后预测。

## 🌐 在线访问

访问地址：[https://your-username.github.io/lanxin-diagnosis/](https://your-username.github.io/lanxin-diagnosis/)

## 📱 手机端使用

直接在手机浏览器中打开上述链接即可使用，支持：
- iOS Safari
- Android Chrome
- 微信内置浏览器

## ✨ 主要功能

- 🏥 **疾病问诊** - 智能导诊、症状采集、风险评估
- 🔬 **智能诊断** - 多模态数据整合、鉴别诊断、分期评估
- 📊 **预后预测** - 生存预测、复发风险评估
- 📝 **病历生成** - 智能信息提取、专科病历格式生成
- 💬 **智能问答** - 专业问题解答、患者教育
- 📚 **科研教学** - 临床研究支持、教学案例库
- 📖 **循证决策** - 最新临床指南、研究证据

## 🎯 支持的肿瘤类型

- 宫颈癌
- 卵巢癌
- 子宫内膜癌
- 乳腺癌

## 🚀 本地运行

### 安装依赖
```bash
pip install -r requirements.txt
```

### 启动服务
```bash
python run.py
```

### 访问系统
打开浏览器访问：http://localhost:5000

## 📦 技术栈

- **后端**: Flask, Python
- **前端**: Bootstrap 5, JavaScript
- **AI模型**: 可配置接入各类医疗AI模型
